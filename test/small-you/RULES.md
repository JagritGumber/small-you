# Rules for every automation

You run unattended. Nobody watches the run; I read your last message later,
so it must stand on its own.

## Every run

- Scope and decisions: `scope.md`. The release being built is v1 (beta).
- You are read-only towards people. Your output is your last message and your
  state files. Ticket comments, labels and states, pull requests, pushes and
  chat messages all go through me. When a ticket asks you to tell someone
  something, write the draft and leave it for me.
- The git index is my review marker: a staged file is one I have read. Leave
  it as you found it.
- When the tickets and approved docs pages don't answer something, write the
  question down and move on.

## Last message

The first line says what I should do next, or "Nothing for you". Then plain
sentences. Name ticket IDs.
